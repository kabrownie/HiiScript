Hiiscript — quick guide

Plain text on the left, formatted screenplay on the right. Recovery snapshots are saved on this device automatically; use Save to write a draft file.

Core formatting components

INT. HOUSE - DAY
EXT. PARK - NIGHT		Scene headings (sluglines) — auto-detected when you type INT, EXT, EST, I/E. Forces . prefix.
Action textAction lines — present-tense description. Force with ! prefix.
MARYCharacter names — all-caps line automatically indented and set above dialogue. Force with @.
Hello, world.Dialogue — indented under the character name automatically.
(whispering)Parentheticals — auto-indented between character and dialogue.
CUT TO:Transitions — right-aligned. FADE IN:, FADE OUT., SMASH CUT TO:, DISSOLVE TO: all recognized. Force with >.

Auto-complete

Start a line with INT, EXT, FADE, CUT, DISSOLVE… and a suggestion list appears. Press Enter or click to accept, Esc to dismiss, ↑/↓ to navigate.

Title page

Start the file with Key: value lines (two or more): Title: Credit: Author: Source: Draft date: Contact:

Importing a PDF

Drop in a screenplay PDF — the importer reads the text positions to reconstruct scene headings, action, characters, dialogue and transitions. It needs an internet connection the first time to fetch the PDF reader, then it's cached for offline use.

Running it like an app

Press ⤓ Run to download Hiiscript.bat (Windows) and hiiscript.sh (Linux). Save this page as Hiiscript.html in the same folder, then double-click the launcher. On Linux run chmod +x hiiscript.sh once.

Created by Kabrownie Digital.

Hiiscript is an offline-first screenplay writer for Fountain scripts. It is designed to keep writing, drafts, and exports under the writer's control.

Privacy policy

Your scripts stay on your device. The app stores recovery snapshots, drafts, settings, characters, and scene suggestions in local browser storage. Draft files are written only when you choose Save, and only to the location you select.

Hiiscript does not include accounts, advertising, analytics, tracking pixels, or background uploads. Two exceptions, both opt-in or clearly disclosed:

  • Update checks (opt-in). If enabled, the app requests the latest release tag from api.github.com at most once every six hours. This shares your IP address with GitHub; nothing else is sent.
  • PDF import (first use only). The bundled PDF.js reader is used offline. If the bundled copy is missing, the app falls back to a public CDN for the reader script.
