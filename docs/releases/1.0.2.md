# Hiiscript 1.0.2

## Highlights

- Offline screenplay editor for Fountain-based writing.
- Local recovery snapshots to protect unsaved work after crashes.
- Character and scene library management with normalization and deduplication.
- Import/export support for script drafts, Fountain text, and Markdown.
- Desktop builds for Windows and Linux, plus Android packaging support.

## Release notes

This release prepares Hiiscript for a broader 1.0.2 distribution pass across desktop and Android targets. The app remains fully offline-first and stores scripts locally on the user's device.

## Security and distribution

- Windows and Linux artifacts are built through the release workflow.
- SHA-256 checksums are generated for release assets.
- Signed Windows installers require the repository secrets `WINDOWS_CERTIFICATE_BASE64` and `WINDOWS_CERTIFICATE_PASSWORD`.
- Android APK builds should be generated from the local project using Capacitor and Android Studio or Gradle.

Screenshots for the release page belong in `docs/screenshots/` and are uploaded automatically when present.
