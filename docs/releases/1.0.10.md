# Hiiscript 1.0.10

Packaging release. For the full feature list see [1.0.0](./1.0.0.md).

## Distribution

- Windows and Linux artifacts are built through the release workflow.
- SHA-256 checksums are generated for release assets.
- Signed Windows installers require `WINDOWS_CERTIFICATE_BASE64` and
  `WINDOWS_CERTIFICATE_PASSWORD` repository secrets.
- Android APKs are built locally via Capacitor and Android Studio or Gradle.

Screenshots for the release page belong in `docs/screenshots/` and are
uploaded automatically when present.
