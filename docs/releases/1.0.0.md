# Hiiscript 1.0.0

## Highlights

- Offline screenplay editor with Fountain formatting and live preview.
- Local recovery snapshots protect unsaved work after a crash.
- Undo and redo, find and replace, scene navigation, focus mode, and writing statistics.
- Fountain and Markdown export, PDF and Final Draft import, and portable JSON drafts.
- Keyboard-accessible dialogs and autocomplete.

## Security and distribution

- Windows and Linux artifacts are built by GitHub Actions.
- SHA-256 checksums are published with every tagged release.
- Configure the Windows certificate secrets in the repository to publish signed installers and remove the unknown-publisher warning.

Screenshots for the release page belong in `docs/screenshots/` and are uploaded automatically when present.
